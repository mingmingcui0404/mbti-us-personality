# MBTI US Personality

Standalone static landing page and 16 result pages for the US MBTI personality site.

## Structure

- `en/index.html` - US landing page
- `en/results/` - 16 personality type result pages
- `assets/` - shared CSS and JavaScript
- `robots.txt` and `sitemap.xml` - SEO crawler files
- `wrangler.toml` - Cloudflare Pages configuration

## Deploy

This site is designed to deploy as a static Cloudflare Pages project from the repository root.
